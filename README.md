# 定点写真 比較ビューア

同じ場所から撮影した写真を、タイムライン・左右スライダー・フェード・差分表示で比較する、GitHub Pages向けの静的サイトです。外部ライブラリやビルド作業は不要です。

## 写真の準備

`assets/photos/` フォルダを作り、次の7枚を元のファイル名のまま置いてください。

- `After20260818_Mitsui_20250804.jpg`
- `After20260818_Mitsui_20251007.jpg`
- `After20260818_Mitsui_20251203.jpg`
- `After20260818_Mitsui_20260210.jpg`
- `After20260818_Mitsui_20260406.jpg`
- `After20260818_Mitsui_20260609.jpg`
- `After20260818_Mitsui_20260818.jpg`

写真がない場合は、日付と不足ファイル名を示す仮画像が表示されます。

## 写真を追加する

1. 写真を `assets/photos/` に追加します。
2. `data.js` の `photos` 配列に、撮影日とファイル名を1行追加します。

```js
{ date: "2026-10-01", file: "After20261001_Mitsui_20261001.jpg" }
```

## ローカルで確認する

このフォルダで次を実行し、ブラウザで `http://localhost:8000` を開きます。

```bash
python -m http.server 8000
```

## GitHub Pagesで公開する

1. GitHubで新しい公開リポジトリを作成します。
2. このフォルダ内の全ファイルをリポジトリへアップロードします。
3. リポジトリの `Settings` → `Pages` を開きます。
4. `Build and deployment` の `Source` を `Deploy from a branch` にします。
5. Branchを `main`、フォルダを `/(root)` にして保存します。

数分後、`https://ユーザー名.github.io/リポジトリ名/` で公開されます。

## 撮影・書き出しの推奨

- 全画像を同じ縦横比・同じピクセル寸法にします。
- レンズ補正と水平補正を統一します。
- わずかな構図ずれも「差分」では強く出るため、必要ならPhotoshop等で基準画像に位置合わせします。
- Web公開用は長辺2400〜3200px、JPEG品質75〜85程度を目安にすると、画質と通信量を両立しやすくなります。
- 公開前に、写り込んだ人物・車両番号・住宅情報などを確認してください。
